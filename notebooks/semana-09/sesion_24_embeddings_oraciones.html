Sesión 24 — Embeddings de oraciones

Curso: Deep Learning · Universidad Externado de Colombia

Propósito y evidencia

Pasaremos de vectores por token a un vector por oración, entrenaremos un bi-encoder pequeño y construiremos recuperación semántica top-k.

import os
os.environ["TF_CPP_MIN_LOG_LEVEL"]="2"
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras

SEED=42
keras.utils.set_random_seed(SEED)

1. Un vector por token todavía no representa el documento

sentences=np.array([
    "sube el precio del café", "aumenta el valor del café",
    "cae el precio del café", "disminuye el valor del café",
    "crecen las exportaciones", "aumentan las ventas externas",
    "llueve en bogotá", "hay precipitaciones en bogotá",
])
vectorizer=keras.layers.TextVectorization(max_tokens=100,output_mode="int",output_sequence_length=8)
vectorizer.adapt(sentences)
ids=vectorizer(sentences)
print(ids.shape,vectorizer.get_vocabulary()[:12])

2. El promedio debe ignorar padding

embedding=keras.layers.Embedding(len(vectorizer.get_vocabulary()),12,mask_zero=True)
tokens=embedding(ids)
mask=embedding.compute_mask(ids)
manual=np.array([row[m].numpy().mean(axis=0) for row,m in zip(tokens,mask)])
pooled=keras.layers.GlobalAveragePooling1D()(tokens,mask=mask).numpy()
np.testing.assert_allclose(manual,pooled,rtol=1e-6,atol=1e-6)
print("embedding de oración:",pooled.shape)

3. Un bi-encoder comparte todos sus pesos

inp=keras.Input((8,),dtype="int32")
x=keras.layers.Embedding(len(vectorizer.get_vocabulary()),16,mask_zero=True)(inp)
x=keras.layers.Bidirectional(keras.layers.LSTM(8))(x)
x=keras.layers.Dense(12)(x)
x=keras.layers.UnitNormalization(axis=-1)(x)
encoder=keras.Model(inp,x,name="encoder_compartido")

left=keras.Input((8,),dtype="int32"); right=keras.Input((8,),dtype="int32")
similarity=keras.layers.Dot(axes=-1)([encoder(left),encoder(right)])
bi_encoder=keras.Model([left,right],similarity)
bi_encoder.compile(optimizer=keras.optimizers.Adam(.01),
                   loss=keras.losses.BinaryCrossentropy(from_logits=True))
assert bi_encoder.get_layer("encoder_compartido") is encoder

4. Pares positivos y negativos definen la geometría

positive=[(0,1),(2,3),(4,5),(6,7)]
negative=[(0,2),(1,6),(3,4),(5,7),(0,6),(2,5)]
pairs=positive+negative
left_ids=tf.gather(ids,[a for a,b in pairs]); right_ids=tf.gather(ids,[b for a,b in pairs])
targets=np.array([1]*len(positive)+[0]*len(negative),dtype="float32")
history=bi_encoder.fit([left_ids,right_ids],targets,epochs=80,verbose=0)
print("pérdida inicial/final:",history.history["loss"][0],history.history["loss"][-1])
assert history.history["loss"][-1]<history.history["loss"][0]

5. Coseno es producto punto después de normalizar

sentence_vectors=encoder(ids).numpy()
norms=np.linalg.norm(sentence_vectors,axis=1)
np.testing.assert_allclose(norms,1,atol=1e-5)
cosine=sentence_vectors@sentence_vectors.T
display(pd.DataFrame(cosine,index=sentences,columns=sentences).round(2))

6. Recuperar es ordenar por similitud

def search(query,k=3):
    query_ids=vectorizer(np.array([query]))
    query_vector=encoder(query_ids).numpy()[0]
    scores=sentence_vectors@query_vector
    order=np.argsort(-scores)[:k]
    return pd.DataFrame({"documento":sentences[order],"similitud":scores[order]})

display(search("el café aumenta de precio"))

7. Recuperación léxica y semántica fallan de modo distinto

query="aumentan los envíos al exterior"
lexical=np.array([len(set(query.split())&set(document.split())) for document in sentences])
semantic=sentence_vectors@encoder(vectorizer(np.array([query]))).numpy()[0]
comparison=pd.DataFrame({"documento":sentences,"léxico":lexical,"semántico":semantic})
display(comparison.sort_values("semántico",ascending=False).head(4))

8. Recall@k evalúa el ranking, no solo una pareja

queries=[("sube el café",1),("bajan los precios",3),("más ventas internacionales",5),("clima lluvioso",7)]
hits=[]
for query,relevant in queries:
    q=encoder(vectorizer(np.array([query]))).numpy()[0]
    top2=np.argsort(-(sentence_vectors@q))[:2]
    hits.append(int(relevant in top2))
print("Recall@2:",np.mean(hits),hits)

Actividad y cierre

Construya el recorrido completo: texto → ids → vectores de token → encoder → pooling → normalización → similitud → top-k. Compare un fallo léxico y uno semántico. Un embedding de oración es útil cuando su objetivo de entrenamiento y su evaluación corresponden al uso de recuperación.
