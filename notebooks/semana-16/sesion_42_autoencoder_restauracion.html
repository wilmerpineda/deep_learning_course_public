Sesión 42 · Restauración de fotografías con autoencoders

Pregunta: ¿qué información debe conservar una red para recuperar una imagen dañada?

Construiremos un autoencoder convolucional que recibe imágenes CIFAR-10 con ruido y aprende a reconstruir la versión limpia. Las etiquetas de clase se conservan solo para describir el dataset; no intervienen en el entrenamiento.

Objetivos

  1. Diferenciar entrada dañada, representación latente y objetivo limpio.
  2. Verificar las dimensiones y la razón de compresión del modelo.
  3. Comparar la entrada dañada y la reconstrucción con MSE, PSNR y SSIM.
  4. Estudiar el efecto del tamaño del cuello de botella y una corrupción no vista.

2. Corrupción controlada

La entrada es \(\tilde{x}=\operatorname{clip}(x+\epsilon,0,1)\), con \(\epsilon\sim\mathcal{N}(0,0.15^2)\). El objetivo continúa siendo la fotografía limpia \(x\). Usamos semillas diferentes por partición y nunca ajustamos decisiones con test.

def add_gaussian_noise(images, sigma=SIGMA, seed=SEED):
    rng = np.random.default_rng(seed)
    noise = rng.normal(0.0, sigma, size=images.shape).astype("float32")
    return np.clip(images + noise, 0.0, 1.0).astype("float32")

x_train_noisy = add_gaussian_noise(x_train, seed=SEED + 1)
x_val_noisy = add_gaussian_noise(x_val, seed=SEED + 2)
x_test_noisy = add_gaussian_noise(x_test, seed=SEED + 3)

assert x_train_noisy.shape == x_train.shape
assert np.mean(np.abs(x_train_noisy - x_train)) > 0.05
print("Cambio absoluto medio:", float(np.mean(np.abs(x_train_noisy - x_train))))
fig, axes = plt.subplots(2, 8, figsize=(13, 4))
for i in range(8):
    axes[0, i].imshow(x_train[i])
    axes[1, i].imshow(x_train_noisy[i])
    axes[0, i].axis("off")
    axes[1, i].axis("off")
axes[0, 0].set_ylabel("Limpia")
axes[1, 0].set_ylabel("Dañada")
plt.suptitle(f"Corrupción gaussiana, σ={SIGMA}")

3. Arquitectura

El encoder reduce la resolución 32→16→8→4. Una convolución 1×1 controla los canales del cuello de botella. El decoder recupera la resolución con convoluciones transpuestas.

def build_autoencoder(latent_channels=32):
    image = keras.Input(shape=(32, 32, 3), name="imagen_danada")
    x = layers.Conv2D(32, 3, strides=2, padding="same", activation="relu", name="enc_16")(image)
    x = layers.Conv2D(64, 3, strides=2, padding="same", activation="relu", name="enc_8")(x)
    x = layers.Conv2D(128, 3, strides=2, padding="same", activation="relu", name="enc_4")(x)
    latent = layers.Conv2D(latent_channels, 1, padding="same", activation="relu", name="latent")(x)
    encoder = keras.Model(image, latent, name=f"encoder_c{latent_channels}")

    code = keras.Input(shape=(4, 4, latent_channels), name="codigo_latente")
    x = layers.Conv2D(128, 3, padding="same", activation="relu", name="dec_proyeccion")(code)
    x = layers.Conv2DTranspose(64, 3, strides=2, padding="same", activation="relu", name="dec_8")(x)
    x = layers.Conv2DTranspose(32, 3, strides=2, padding="same", activation="relu", name="dec_16")(x)
    x = layers.Conv2DTranspose(16, 3, strides=2, padding="same", activation="relu", name="dec_32")(x)
    reconstruction = layers.Conv2D(3, 3, padding="same", activation="sigmoid", name="reconstruccion")(x)
    decoder = keras.Model(code, reconstruction, name=f"decoder_c{latent_channels}")

    autoencoder = keras.Model(image, decoder(encoder(image)), name=f"autoencoder_c{latent_channels}")
    autoencoder.compile(optimizer=keras.optimizers.Adam(1e-3), loss="mse")
    return autoencoder, encoder, decoder

autoencoder, encoder, decoder = build_autoencoder(latent_channels=32)
assert autoencoder.output_shape == (None, 32, 32, 3)
assert encoder.output_shape == (None, 4, 4, 32)
autoencoder.summary()
INPUT_VALUES = 32 * 32 * 3
latent_shape = encoder.output_shape[1:]
LATENT_VALUES = int(np.prod(latent_shape))
compression_ratio = INPUT_VALUES / LATENT_VALUES

shape_ledger = pd.DataFrame({
    "objeto": ["entrada", "cuello", "salida"],
    "shape": [(32, 32, 3), latent_shape, (32, 32, 3)],
    "valores": [INPUT_VALUES, LATENT_VALUES, INPUT_VALUES],
})
display(shape_ledger)
print(f"Razón de compresión nominal: {compression_ratio:.1f}:1")
print(f"Parámetros entrenables: {autoencoder.count_params():,}")

Entrenamos con entrada dañada y objetivo limpio. Early stopping observa únicamente la pérdida de validación.

5. Evaluación

La referencia mínima devuelve la entrada dañada sin modificarla. El autoencoder debe mejorar esa referencia sobre las mismas imágenes de test.

def image_metrics(clean, prediction):
    clean_t = tf.convert_to_tensor(clean, dtype=tf.float32)
    pred_t = tf.convert_to_tensor(prediction, dtype=tf.float32)
    return {
        "MSE": float(tf.reduce_mean(tf.square(clean_t - pred_t))),
        "PSNR_dB": float(tf.reduce_mean(tf.image.psnr(clean_t, pred_t, max_val=1.0))),
        "SSIM": float(tf.reduce_mean(tf.image.ssim(clean_t, pred_t, max_val=1.0))),
    }

x_test_reconstructed = autoencoder.predict(x_test_noisy, batch_size=BATCH_SIZE, verbose=0)
results = pd.DataFrame([
    {"modelo": "Entrada dañada", **image_metrics(x_test, x_test_noisy)},
    {"modelo": "Autoencoder c32", **image_metrics(x_test, x_test_reconstructed)},
]).set_index("modelo")
display(results.round(4))
def show_reconstructions(clean, corrupted, reconstructed, n=7, start=0):
    fig, axes = plt.subplots(4, n, figsize=(2 * n, 8))
    rows = [clean, corrupted, reconstructed, np.abs(clean - reconstructed)]
    labels = ["Limpia", "Dañada", "Reconstruida", "Error absoluto"]
    for row, (images, label) in enumerate(zip(rows, labels)):
        for col in range(n):
            image = images[start + col]
            if row == 3:
                axes[row, col].imshow(image.mean(axis=-1), cmap="magma", vmin=0, vmax=0.5)
            else:
                axes[row, col].imshow(np.clip(image, 0, 1))
            axes[row, col].axis("off")
        axes[row, 0].set_ylabel(label, fontsize=10)
    plt.tight_layout()
    plt.show()

show_reconstructions(x_test, x_test_noisy, x_test_reconstructed)

6. Mini-reto: tamaño del cuello de botella

Cada pareja trabaja con 16 o 64 canales. No cambie la partición, las semillas, el ruido, el optimizador ni el presupuesto. Registre parámetros, dimensión latente, razón de compresión, tiempo, PSNR, SSIM, una reconstrucción representativa y un caso fallido.

RUN_CHALLENGE = False  # Cambiar a True durante el mini-reto

if RUN_CHALLENGE:
    challenge_model, challenge_encoder, _ = build_autoencoder(LATENT_CHANNELS_CHALLENGE)

    challenge_history = challenge_model.fit(
        x_train_noisy, x_train,

7. Corrupción no vista: oclusión

El modelo solo vio ruido gaussiano. Antes de ejecutar, prediga qué ocurrirá cuando una región de 8×8 píxeles desaparezca por completo.

def add_center_occlusion(images, size=8):
    occluded = images.copy()
    start = (images.shape[1] - size) // 2
    occluded[:, start:start + size, start:start + size, :] = 0.0
    return occluded

x_test_occluded = add_center_occlusion(x_test, size=8)
x_test_inpainted = autoencoder.predict(x_test_occluded, batch_size=BATCH_SIZE, verbose=0)
ood_results = pd.DataFrame([
    {"modelo": "Entrada ocluida", **image_metrics(x_test, x_test_occluded)},
    {"modelo": "Autoencoder entrenado con ruido", **image_metrics(x_test, x_test_inpainted)},
]).set_index("modelo")
display(ood_results.round(4))
show_reconstructions(x_test, x_test_occluded, x_test_inpainted)
