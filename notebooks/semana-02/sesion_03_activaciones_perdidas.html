3. Funciones y derivadas locales

Implemente primero la definición. Después compare la forma y localice regiones donde la derivada se aproxima a cero.

z = np.linspace(-7, 7, 500)
sigmoid = 1.0 / (1.0 + np.exp(-z))
tanh = np.tanh(z)
relu = np.maximum(z, 0.0)
functions = {
    'ReLU': (relu, (z > 0).astype(float)),
    'sigmoid': (sigmoid, sigmoid * (1 - sigmoid)),
    'tanh': (tanh, 1 - tanh**2),
}
fig, axes = plt.subplots(2, 3, figsize=(12, 6), sharex=True)
for col, (name, (value, derivative)) in enumerate(functions.items()):
    axes[0, col].plot(z, value); axes[0, col].set_title(name)
    axes[1, col].plot(z, derivative, color='#b45309'); axes[1, col].set_title(f"derivada de {name}")
for ax in axes.ravel(): ax.axhline(0, color='black', lw=.6); ax.grid(alpha=.25)
plt.tight_layout(); plt.show()

4. Softmax estable

Restar el máximo de cada fila no altera las probabilidades y evita calcular exponenciales enormes.

def stable_softmax(logits):
    shifted = logits - logits.max(axis=-1, keepdims=True)
    exp_values = np.exp(shifted)
    return exp_values / exp_values.sum(axis=-1, keepdims=True)

logits = np.array([[2.0, 1.0, -1.0], [1002.0, 1001.0, 999.0]])
p_numpy = stable_softmax(logits)
p_keras = keras.activations.softmax(tf.constant(logits)).numpy()
print(p_numpy)
print('Filas suman uno:', np.allclose(p_numpy.sum(axis=1), 1.0))
print('NumPy = Keras:', np.allclose(p_numpy, p_keras, atol=1e-7))

5. Pérdidas ante distinta confianza

BCE distingue errores que accuracy trata como iguales. Para \(y=1\), compare probabilidades desde una equivocación confiada hasta un acierto confiado.

eps = 1e-7
p = np.linspace(.001, .999, 500)
bce_y1 = -np.log(np.clip(p, eps, 1 - eps))
bce_y0 = -np.log(np.clip(1 - p, eps, 1 - eps))
plt.figure(figsize=(7, 4))
plt.plot(p, bce_y1, label='y=1'); plt.plot(p, bce_y0, label='y=0')
plt.xlabel('probabilidad estimada de y=1'); plt.ylabel('BCE por caso')
plt.ylim(0, 7); plt.grid(alpha=.25); plt.legend(); plt.show()

audit = pd.DataFrame({'y': [1, 1, 1], 'p': [.01, .49, .99]})
audit['accuracy_umbral_.5'] = (audit.p >= .5) == audit.y
audit['BCE'] = -np.log(audit.p)

6. La señal local \(\hat p-y\)

Comprobamos con autodiferenciación que sigmoid más BCE produce esa derivada respecto del logit. No propagaremos todavía la señal hacia otras capas.

z_tf = tf.Variable([[-2.0], [0.0], [2.0]], dtype=tf.float32)
y_tf = tf.constant([[1.0], [0.0], [1.0]])
with tf.GradientTape() as tape:
    loss_by_case = keras.losses.binary_crossentropy(y_tf, z_tf, from_logits=True)
    total = tf.reduce_sum(loss_by_case)
gradient = tape.gradient(total, z_tf).numpy().ravel()
p_tf = tf.sigmoid(z_tf).numpy().ravel()
expected = p_tf - y_tf.numpy().ravel()
pd.DataFrame({'z': z_tf.numpy().ravel(), 'y': y_tf.numpy().ravel(), 'p': p_tf, 'gradiente': gradient, 'p-y': expected})
