Embedding como tabla

\[ E\in\mathbb R^{V\times d},\qquad z_i=E[i]=e_i^TE. \]

Objeto Shape Parámetros
ids \((B,T)\) 0
tabla \(E\) \((V,d)\) \(Vd\)
salida \((B,T,d)\) 0 adicionales
máscara \((B,T)\) 0

Con promedio \(r=(E[i]+E[j])/2\), logit \(a=r^Tw\) y BCE:

\[ \frac{\partial L}{\partial E[i]}=\frac12(\sigma(a)-y)w. \]

Word2Vec

Skip-gram

\[ s(c,o)=u_c^Tv_o,qquad p(y=1\mid c,o)=\sigma(s). \]

\[ \mathcal L=-y\log\sigma(s)-(1-y)\log(1-\sigma(s)). \]

Usa dos tablas de shape \((V,d)\): centro y contexto. Negative sampling convierte pares observados/no observados en una tarea binaria.

CBOW

Promedia los vectores de varios tokens de contexto y predice el token central.

GloVe

\[ J=\sum_{i,j}f(X_{ij}) \left(w_i^T\tilde w_j+b_i+\tilde b_j-\log X_{ij}\right)^2. \]

\(X_{ij}\) resume coocurrencias del corpus. Transferir el resultado exige conservar exactamente el mapeo token → fila.

Régimen Pesos iniciales ¿Se actualiza \(E\)?
desde cero aleatorios sí

fine-tuning preentrenados sí

Self-attention

\[ Q=XW_Q,\quad K=XW_K,\quad V=XW_V, \]

\[ A=softmax(QK^T/\sqrt{d_k}+M),\qquad Z=AV. \]

Objeto Shape multi-head
entrada \((B,T,d_{model})\)
Q/K/V \((B,H,T,d_k)\)
scores \((B,H,T,T)\)
salida concatenada \((B,T,Hd_v)\)
proyección final \((B,T,d_{model})\)

La máscara se aplica antes del softmax. Cada fila final sobre keys válidas suma uno.

Encoder Transformer

token embedding + posición
→ multi-head attention
→ residual + layer normalization
→ feed-forward por token
→ residual + layer normalization

Las sumas residuales requieren el mismo \(d_{model}\) a ambos lados.

Embedding de oración

Promedio enmascarado:

\[ s=\frac{\sum_t m_t h_t}{\sum_t m_t}, \qquad \bar s=\frac{s}{\|s\|}. \]

Con documentos normalizados como filas de \(D\) y consulta \(q\):

\[ scores=Dq,qquad top_k=argsort(-scores)[:k]. \]

Lista de auditoría

Antes de interpretar un embedding, verificar:

  1. unidad representada: token, posición, oración o documento;
  2. vocabulario, PAD, UNK, truncamiento y máscara;
  3. corpus y objetivo que produjeron la geometría;
  4. split usado para adaptar tokenizer o construir coocurrencias;
  5. normalización y métrica de similitud;
  6. estabilidad entre semillas;
  7. evaluación extrínseca frente a un baseline;
  8. errores por longitud, tema, fuente o dominio;
  9. posibles atajos, sesgos y límites del uso previsto.
